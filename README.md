# Report · косвенная речь B1 → B2

Личное приложение для iPhone и iPad с установкой через Safari на экран «Домой».

Постоянная ссылка: https://evgk724.github.io/reported-speech/

16 коротких тем, 160 заданий и карточки по пять примеров. Для каждого задания заданы исходная фраза, говорящий и ситуация пересказа. Утверждения, вопросы, просьбы, местоимения, времена, контекст, модальные глаголы и более точные reporting verbs.

Тёмный графитовый интерфейс, базовый текст 18 px с настройками 20/22 px. Все английские примеры озвучены заранее голосом Microsoft en-GB-RyanNeural. В тренировках принимаются подготовленные грамматически допустимые варианты, в том числе необязательное that и if / whether. Самостоятельный пересказ вслух оценивает сам учащийся; микрофон не записывается.

## Учебный цикл

Прочитать короткое объяснение → восстановить из памяти → проверить → повторить позже. Очередь «Сегодня» сначала предлагает карточки, срок повторения которых подошёл, затем новые. Основные интервалы 1, 3, 7, 14, 30, 60, 120, 180 дней; ответы меняют интервал. Ошибка повторяется в текущем занятии не более одного раза и сохраняется в личном разделе. Два успешных ответа в разные последующие дни убирают её из списка трудных. Дополнительная практика до срока не увеличивает интервал искусственно.

## Установка и хранение

Safari → «Поделиться» → «На экран Домой» → «Добавить». Для работы без сети: настройки → «Сохранить уроки и аудио», дождаться завершения.

Прогресс хранится только в localStorage этого браузера или установленного веб-приложения. Устройства автоматически не синхронизируются. Резервную копию JSON можно экспортировать и импортировать через настройки. Safari и установленное приложение могут иметь отдельные хранилища. Очистка данных сайта удаляет прогресс; iOS может освобождать офлайн-кеш при нехватке места.

Кеш Report и ключ прогресса отделены от Tense, Article, Verb и Phrase. Нет регистрации, аналитики, рекламы или API ключей.

## Проверка

`npm test` проверяет содержание, допустимые ответы, интервалы, резервные копии, аудио и service worker. `node tests/browser.cjs` проверяет интерфейс и учебные сценарии в Chromium; `QA_BROWSER=webkit node tests/browser.cjs` — в WebKit. GitHub Actions запускает оба браузера.

Материал опирается на Cambridge English Grammar Today и British Council LearnEnglish. Примеры и объяснения подготовлены для этого курса. Источники доступны в настройках приложения.
